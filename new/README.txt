CIVICFIX - HTML/CSS/JavaScript Mini Project Demo

FILES
- index.html      Home/dashboard
- report.html     Submit a public issue
- track.html      Track complaint status
- issues.html     Public issue board
- admin.html      Admin dashboard
- style.css       Responsive styling
- script.js       Interactivity and LocalStorage

HOW TO RUN
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. No server or backend is required.

DEMO
- Report a new issue from Report Issue. It is saved in browser LocalStorage.
- Track it using the generated complaint ID.
- Public Issues shows demo + submitted reports.
- Admin lets you change statuses of locally saved complaints.

IMPORTANT
This is an educational frontend prototype. It does not submit complaints to a real municipality/government department and does not store data on a server.

LOGO
- civilfix-logo.png is the supplied CivicFix logo and is used in the navbar on every page.
